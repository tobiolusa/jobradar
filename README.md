# JobRadar

A lightweight Python bot that monitors job listing feeds and instantly sends new postings to your Telegram chat. Built for freelancers who want to be first to apply.

## Features

- Monitors RSS/Atom job feeds (WordPress Jobs, and more)
- Sends instant Telegram notifications for new listings
- Tracks state between runs — no duplicate alerts
- Resilient to network errors and malformed feeds
- Easy to extend with new job sources
